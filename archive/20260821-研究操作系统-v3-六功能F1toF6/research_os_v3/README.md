# Personal Research OS v3.0

## 六个核心功能
1. 读论文
2. 论文分类、标签、存储并形成记忆
3. 对记忆深度思考、联想与辩论
4. 形成论文结构设计
5. 实证 / 案例研究方法分析与执行
6. 核查结果、回溯与自检

## 总循环
Human Goal → Function Router → Skill → Permission → Model → Runtime → Validation → Human Checkpoint → Memory Update

## 上位原则
真人专家实践 → 专家蒸馏 → Validated Skill → Gateway → 执行 → 验证 → 研究记忆复利。
