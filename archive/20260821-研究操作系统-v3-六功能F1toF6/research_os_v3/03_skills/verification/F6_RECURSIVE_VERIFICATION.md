# F6 Verification & Recursive Backtracking

## Core loop
Claim → Evidence → Logic → Alternative Explanation → Verification → PASS/FAIL

## Backtracking
FAIL时定位最早失效节点：source / extraction / classification / conceptualization / mechanism / design / computation / interpretation / writing。

## Verification layers
1 source 2 evidence 3 computation 4 logic 5 rival explanation 6 claim-evidence alignment 7 narrative consistency

## Stop
只有关键claim全部通过必要验证才停止。
