# 企业知识结构指标：定义、构造约定与数据质量检查清单

本文档收录与数据库无关的稳定知识：指标精确定义、构造约定、换库后的数据质量检查清单。
计算实现见 `scripts/knowledge_indicators.py`，不要按本文档重写代码。

---

## 一、指标定义

记号：企业（上市公司集团）i，年份 t。C_it 为企业 i 在年份 t **发明专利**所覆盖的主 IPC
四位类别集合；P_it 为 t 年发明专利集合，N_it = |P_it|，n_{i,c,t} 为其中类别 c 的专利数。

### Y1 知识宽度 / 技术类别

- **FieldNum_it = |C_it|**：t 年发明专利主 IPC4 去重计数。
- **Width_it = 1 − Σ_c s²_{i,c,t}**，其中 s_{i,c,t} = n_{i,c,t} / N_it 为类别 c 的占比
  （赫芬达尔指数 1−HHI）。N_it = 0 时无定义（NaN）。
- **ΔFieldNum_{i,t+1} = FieldNum_{i,t+1} − FieldNum_{i,t}**
- **ΔWidth_{i,t+1} = Width_{i,t+1} − Width_{i,t}**

### Y2 既有领域再生产

- **ReuseCount_{i,t+1} = ln(1 + #{p ∈ P_{i,t+1} : c(p) ∈ C_it})**：
  t+1 年发明专利中主 IPC4 落在 t 年既有领域集合内的专利数，取 ln(1+x)。
- **ReuseShare_{i,t+1} = 上述数量 / |P_{i,t+1}|**；|P_{i,t+1}| = 0 时 NaN。

### M1 新知识搜索

- E_it = 企业 t 年**有效外部引用**（is_valid=True 且 cited_in_group=False）所覆盖的
  cited_ipc4 集合（缺失值不计入）。
- E^H_it = 该企业在 **t−5 至 t−1** 年有效外部引用类别的并集。
- **NewSearchCount_it = ln(1 + |E_it \ E^H_it|)**；集合差为空集时天然为 ln(1+0) = 0。
- **NewSearchShare_it = |E_it \ E^H_it| / |E_it|**；|E_it| = 0 时 NaN。

### M2 内部知识重用

- **SelfCite_win_it**：企业 t 年发明专利的有效引用中，被引专利属于同一集团且
  cited_app_year ∈ [t−5, t−1] 的次数。
- **SelfCite_all_it**（稳健口径）：同上但被引年份条件放宽为 cited_app_year < t
  （t 年以前全部历史）。两种口径并行报告，列名区分。
- **BackCite_it** = t 年发明专利全部有效后向引用次数。
- **InternalReuseCount_it = ln(1 + SelfCite_win_it)**。
- **InternalReuseShare_it = SelfCite_win_it / BackCite_it**；BackCite = 0 时 NaN。

### W 既有外部知识搜索开放度

- **Open_{i,t−1} = 1 − Σ_c q²_{i,c,t−1}**，q_{i,c,t−1} 为该企业在 t−5 至 t−1 年历史
  窗口内有效外部引用在各 cited_ipc4 类别上的分布份额。窗口内无有效外部引用时 NaN。
- 在计算脚本的 (group_id, year) 面板中，行年份 y 的 Open 对应窗口 [y−4, y]；
  回归中 W 用 t−1 年值，即把 Open 滞后一年入模。

## 二、构造约定

1. **多申请人专利**：每个申请人集团各自分别计一次。在适配层按申请人展开为多条记录
   （同一 patent_id 在每个归属集团下各出现一条），计算层不做跨集团去重。
2. **Y 类指标只用发明专利**（is_invention=True）。
3. **引用类指标一律按 is_valid 标记筛选**。有效引用类型的取舍规则（例如原始库中
   X/Y/A/L 等引用类型哪些算"有效"）属适配层职责，在适配层打好 is_valid 标记。
4. **历史窗口一律 t−5 至 t−1**；M2 稳健口径扩展至 t 年以前全部历史。
5. **数量指标与比例指标必须并行报告**——数量可能随专利总量机械增长，只有两者一致
   才能排除规模效应。
6. **时间对齐**：解释变量在 t 年（M1/M2 用 t 年值，W 用 t−1 年值），Y1/Y2 结果变量
   在 t+1 年（ΔWidth_{t+1}、ΔFieldNum_{t+1}、Reuse_{t+1}）。面板中每行指标以该行
   年份标注，回归前自行 lag/lead 对齐。
7. **Δ 类与 Reuse 类指标以集团 t 年与 t+1 年都有专利记录为前提**；某年无记录时该
   年指标为 NaN，**不要填 0**——除非该指标定义上天然为 0（如集合差为空集时
   NewSearchCount = ln(1+0) = 0）。

## 三、数据质量检查清单（换数据库后第一件事，按顺序做）

> **必须先诊断再定样本窗口**，不能跑完回归才发现截断。

1. **分年份核验收录覆盖率**：统计每年专利数占预期规模的比率。
   教训：上一套库的发明专利覆盖率 2021 = 97.7%、2022 = 61.1%、2023 = 20.3%、
   2024 = 15.0%——发明专利公开滞后导致尾部年份严重截断，2023–2025 年数据不可用。
   按诊断结果确定样本窗口右端点。
2. **检查引用表与专利表的连接率**：被引专利能查到 IPC4 和申请年的比例
   （即 cited_ipc4、cited_app_year 的非缺失率）。连接率过低会直接压低 M1/M2/W。
3. **检查集团标识的唯一性和稳定性**：同一集团是否存在多个标识、同一标识是否对应
   多个集团；无标准化唯一 ID 时以关联股票代码为准。
4. **抽查多申请人展开是否正确**：同一专利是否按集团数重复出现，且每条只出现在
   对应集团下（不多、不少、不错位）。
