# 实证论文工作流 · 使用说明（一页纸）

适用场景：上市公司面板实证（文本构建 X → 专利构建 Y/M/W → 双向 FE 回归）。
原则：**换数据库/换课题时，只有 03 和 07 需要重写，其余直接复用。**

## 数据源登记（X/Y 地址一律留空，每次使用时自填）

> 规则：工作流文件不写死任何 X/Y 数据源地址。换用不同本地数据时，在此登记并在脚本参数中自行填写。

- X（文本词频面板）地址：＿＿＿＿＿＿＿＿＿＿（自填）
- Y（专利指标/面板）地址：＿＿＿＿＿＿＿＿＿＿（自填）
- M/W（专利引用数据）地址：＿＿＿＿＿＿＿＿＿＿（自填）
- 入库前必做：按 `01_指标定义+构造约定+质量清单/` 的数据质量清单做分年份收录诊断。

## 使用顺序

**① 建 X（文本）**：按 `06_交乘识别方法论+验证清单/SKILL.md` 构建词表
（放 `07_词表/`）→ 跑 `08_解析脚本/parse_keyword_panel.py`：
`python 08_解析脚本/parse_keyword_panel.py --texts-dir 年报根目录 --wordlist 07_词表/词表.csv --exclude-rules 07_词表/排除规则.csv --year 2022 --out 输出/shard.csv`
→ 必做验证：抽读 20–50 条触发句查假阳性、报零值比例、严格/宽松双口径并行。

**② 建 Y/M/W（专利）**：按 `01_指标定义+构造约定+质量清单/` 执行——
先按其中 references 的**数据质量清单**对新库做收录诊断（分年份覆盖率→引用连接率→集团标识→多申请人抽查），定样本窗口；
再在 `03_新库→中间表适配/` 写一次性适配代码，产出两张标准中间表
（patents: patent_id/group_id/app_year/main_ipc4/is_invention；
citations: citing_id/cited_ipc4/cited_in_group/cited_app_year/is_valid）；
最后跑 `02_中间表→指标计算/knowledge_indicators.py`：
`python 02_中间表→指标计算/knowledge_indicators.py --patents p.csv --citations c.csv --out panel.csv`
数量与比例指标并行报告，X 在 t、Y 在 t+1 对齐。

**③ 合并面板**：X + Y/M/W + 控制变量按 (股票代码, 年份) 合并成回归数据集，版本化保存（v1、v2…）。

**④ 回归**：按 `05_回归使用规范/SKILL.md`，用 `04_双向FE+聚类+门槛/panel_fe.py`——
基准 `fit_twfe`、异质性 `run_groups`（门类 N≥500、大类 N≥300）、门槛 `threshold`
（全量 b_wild=300/b_pair=200，冒烟先 20）。**不要手写回归**，年份哑变量不可消元。

## 环境红线

- Python 必须在**工作区根目录**运行；根目录 `unicodedata.py` 占位模块不可删（pandas 依赖）；
- Bash 单次 300 秒上限，长任务拆步存检查点；
- 本机无 statsmodels/linearmodels/scipy，回归只能用 04 的脚本。
