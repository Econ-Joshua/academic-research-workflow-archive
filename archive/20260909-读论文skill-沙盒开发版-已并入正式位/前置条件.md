# 读论文 skill · 前置条件

> v0.2。本 skill 是**纯 LLM 分析**，无外部数据获取、无 API Key、无 MCP 依赖——是固定 skill 五件套里前置最简单的一个。

## 运行环境

- 任一带长上下文的 agent（默认 Kimi 类模型；疑难论文可手动点名强模型做 E/D 段复核）。
- 系统层脚本（已有，无需新装）：
  - `paper-inbox.py` —— 入库、建三段落论文页、`--rerun` 整批刷新【理解】段
  - `paper-check.py` —— 校验三段制结构完整
  - 定位：`<系统层>\SCRIPTS\`（系统层 = Academic Research Workflow 根目录）

## 依赖清单

| 依赖 | 类型 | 本 skill 是否新增 | 说明 |
|---|---|---|---|
| paper-inbox.py / paper-check.py | 系统脚本 | 否 | 系统层自带 |
| 论文页（三段制 note-*.md） | 输入 | 否 | paper-inbox.py 自动生成 |
| 知识库 5 个分析文件 | 本 skill | 是 | 随 skill 交付 |
| 研究议程.md | 本 skill | 是 | 你手动维护 |
| 外部数据源 / API Key / MCP | — | 无 | 本 skill 不取外部数据 |

## agent 侧要求（写入你调用 agent 时的约束）

1. 一次通读论文全文后按 9 项顺序产出，**不重复读、不分多个 agent**。
2. 每段字数上限为硬约束；内容不可得写 `—`，可用 `[?]` 标注推断，**不编造**。
3. 产出后写回 `note-<标题>.md` 的【理解】段，**不碰讨论/结论/frontmatter**。
