# 写作结构模板库

阅读本文前：SKILL.md 的 F 段需提取 E 项"可迁移写作结构"。本文件是你的写作结构**批次累积库**——读到有借鉴意义的写法时，把结构模板沉淀在这里；SKILL.md 的 F 段只负责从当前论文提取，本库负责跨论文累积。

## 一文一模板的登记格式

每个值得借鉴的写作结构占一小节，格式固定：

```
### 论文简称（年份，期刊）
- 定位：该结构解决的是什么写作难题
- 结构骨架：intro → 论敌 → 靠理论 → … → 讨论 的分段与顺序
- 可迁移点 / 最大风险
```

## 示例登记（对抗型 Introduction 模板）

> 由 SMJ ByteDance 论文作为基准示例放入，属 v0.2 初稿占位，后续读论文时补充。

### 对抗型 Introduction（基准示例）
- 定位：解决"读起来像教科书复述"问题，让开场就有张力。
- 结构骨架：
  1. 第一句 = 常识/共识（读者点头）
  2. 立刻反转："但本文发现相反方向"
  3. 点出谜团：现有理论为何解释不了
  4. 一句立场声明：本文主张 / 揭示 / 重构
  5. 预告机制链（呼应 B 段七环）与证据
- 可迁移点：用"共识→挑战→谜团"三拍建立张力；第一段就抛出理论敌人。
- 最大风险：反转开场若最终没兑现，会被审稿人抓 overstate。

## 中文顶刊结构与英文顶刊结构的差异映射（提示）

翻译转换本身不在本 skill，但提取写作结构时注意两者差异，用它筛哪些结构值得沉淀：

| 维度 | AMJ/SMJ/ASQ/MS | 《中国工业经济》/《管理世界》 |
|---|---|---|
| 理论定位 | 重机制与构念创新 | 重政策/现实问题进入 + 现实回响 |
| Intro | 学术谜团驱动 | 常从现实/制度/政策现象切入 |
| 讨论 | 理论贡献分层 | 政策启示是必须小节 |
| 行文 | 尽量抽象可迁移 | 更明确的中国情境锚定 |

> 所以：提取写作结构时，优先挑选"机制/构念创新 + 论证张力"类（英文强项）沉淀；政策回响、中国情境锚定类（中文强项）从你的中文文献里单独沉淀。
