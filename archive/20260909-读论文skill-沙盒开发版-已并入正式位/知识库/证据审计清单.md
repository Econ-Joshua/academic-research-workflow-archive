# 证据审计清单

阅读本文前：SKILL.md 的 C 段需审计证据结构。本清单给出证据类型分类、核验问法、以及"支撑机制 vs 只支撑结果"的判定。

## 证据类型分类

| 类型 | 说明 | 强度提示 |
|---|---|---|
| 理论/概念论证 | 逻辑推演、机制叙事 | 提供"为什么"，但不验证"是否真发生" |
| 案例（单/多） | 过程追踪、选择性样本 | 机制深，外推弱；选样偏差是攻击点 |
| 档案/历史数据 | 二手记录、事件史 | 覆盖面大，测量粗糙 |
| 问卷/田野 | 感知数据、访谈 | 构念贴合，但同源偏误；访谈有回溯重构问题 |
| 二手定量（面板/回归/DID） | 大样本因果关系检验 | 识别策略决定可信度 |
| 实验/RCT/自然实验 | 最强因果识别 | 稀缺；外部效度疑问 |
| 仿真/建模 | 逻辑一致性检验 | 证明"可能"，不证明"实际" |

## 五问核验

1. **数据支持的是机制，还是只支持结果？**
   - 打开过程了吗？（有中介测量/过程追踪/时序事件？）→ 是机制证据
   - 只证明 X 与 Y 相关？→ 只支撑结果，机制是解释性叙事
2. **最强证据是什么？**（最能打的一环）
3. **最弱证据是什么？**（最经不起攻击的一环——这是 E 段批评的弹药）
4. **识别策略是否足以排除替代解释？**
   - 有反事实吗？有控制吗？有安慰剂/证伪检验吗？
5. **证据—主张匹配吗？**
   - 主张"机制"却只有"相关性"数据？→ 匹配错位（呼应 D 段 overstate）

## 具体技术要点（记入 F 段可迁移设计）

- 若用**中介**：是正式中介分析，还是仅叙事串联？正式分析是否有因果推断问题（自选择、时变混杂）？
- 若用**过程追踪**：是否展示时序事件链？是否单一路径（遗漏替代路径）？
- 若用**异质性/调节**：调节变量是否理论驱动，还是数据挖掘补上的？
- 若用**二次数据**：测量是否有效度说明？构念—测量是否对齐？
- 若用**案例**：是否透明报告了选样与变异（negative cases）？

## 输出到 C 段

- 一句总判断：证据强度高/中/低，为何。
- 机制证据 or 结果证据 or 两者。
- 最强证据 1、最弱证据 1（各一行）。
