# Expert-Driven Research Skill Kernel v1.0

## 1. 上位原则

Research OS 不以“超级 Agent”为中心，而以“可积累的研究能力”为中心。

> 真人专家实践 → 蒸馏 → Skill → Registry → Method Routing → Model Routing → Runtime Routing → Validation → Human Checkpoint → Memory

## 2. 什么叫“蒸馏”

这里的蒸馏不是传统模型蒸馏，而是 Expert Practice Distillation：

隐性专业知识（tacit expertise）
→ 显性工作流程（explicit workflow）
→ 可操作判断规则（decision rules）
→ 边界/失败/验证/停止规则
→ 可复用 Skill

## 3. 六种核心资产

1. Expert Practice：专家真实做法。
2. Distilled Method：从实践中提炼出的稳定方法。
3. Skill：可调用的程序化能力。
4. Workflow：多个 Skill 的有序组合。
5. Research Memory：经过验证、可复用的研究经验。
6. Governance：人类主权、权限、验证和升级规则。

## 4. 人类主权

默认 Human Sovereign 的任务：
- Research Question Selection
- Conceptual Lens Selection
- Core Mechanism Commitment
- Contribution Positioning
- Evidence Standard
- Research Design Commitment
- Narrative Architecture
- Writing Taste
- Journal Positioning

AI 主要承担：搜索、扩展候选、比较、攻击、提取、批量执行、确定性计算、验证与报告。

## 5. Skill 的最小充分条件

一个方法只有同时具备：
- 稳定目标
- 明确输入
- 稳定流程
- 可表达的判断规则
- 清晰边界
- 可识别失败模式
- 可验证输出
- 停止条件
才允许进入 Candidate Skill。

## 6. Skill 不是什么

不是“成为优秀研究者”、不是“写一篇好论文”、不是“做案例研究”这种无限边界任务。它必须是一个可以定义输入、输出、方法和验收标准的能力单元。

## 7. Gateway 的层次

先 Method，再 Skill，再 Model，再 Runtime：

Task → Method Router → Skill Router → Model Router → Runtime Router → Validation

## 8. Expert Source 优先级

1. 真人专家真实工作实践
2. 多专家交叉验证的方法
3. 优秀 Agent 的执行机制
4. 文献/教材/一般 Prompt 技巧

Agent forensics 只是辅助知识来源，不是 Research OS 的上游主线。
