# Master Workflow

## A. Research Work

Human goal → Task decomposition → Method selection → Skill selection → Model routing → Runtime routing → Execute → Validate → Human checkpoint → Memory

## B. Expert Distillation Work

Expert source → Capture → Workflow reconstruction → Decision rules → Heuristics → Boundaries → Failure modes → Validation rules → Stop conditions → Candidate skill → Expert review → Pilot → Validated skill → Registry

## C. Continuous Improvement

Task result / failure / user correction → classify → decide whether reusable → update Skill or create new Skill → version → test → release
