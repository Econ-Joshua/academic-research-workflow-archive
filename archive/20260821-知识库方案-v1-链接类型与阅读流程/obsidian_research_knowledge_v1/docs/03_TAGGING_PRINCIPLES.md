# Tagging Principles

Tags describe stable attributes. Examples:
- #paper
- #empirical
- #case
- #policy
- #economic-history
- #theory/knowledge-boundary
- #concept/absorptive-capacity
- #mechanism/knowledge-integration
- #method/panel
- #stage/discovery

Do not use tags for transient judgments such as #interesting or #useful. Use prose, ratings, workflow state and links instead.

Use a controlled vocabulary and keep tags sparse. Relations carry intellectual meaning; tags classify.
