# Setup from Zero

1. Create an Obsidian vault named `Research_Vault`.
2. Create the folders in `09_VAULT_STRUCTURE.md`.
3. Copy templates into `90_Templates`.
4. Establish controlled vocabularies for paradigms, stages, theories, methods, relations, reading levels and project IDs.
5. Pilot on 20–50 papers rather than mass-converting the entire library.
6. Run the four-channel reading workflow: Skill Extraction -> Human Reading -> AI Dialogue -> Knowledge Association, then Synthesis -> Meta-Reflection -> Memory update.
7. Validate whether the system reduces cognitive load and preserves human judgment.
8. Automate only after the manual workflow is stable.
