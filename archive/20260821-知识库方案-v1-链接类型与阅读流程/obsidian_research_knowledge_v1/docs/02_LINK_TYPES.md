# Link Types

## Stable structural links
- related-to
- same-construct
- same-method
- same-context
- cites
- cited-by

## Intellectual claim links (review required)
- supports
- contradicts
- extends
- reframes
- complements
- operationalizes
- tests
- challenges

## Research-generation links (strong review required)
- inspires
- suggests-question
- suggests-mechanism
- suggests-design
- method-transfer

A strong relation must state the relation, evidence, whether it is textual or inferential, and candidate/validated status.
