# Agent Systems：次级知识来源

优秀Agent仍值得研究，但它们不是Research OS的最终目标。

它们只是Skill知识的次级来源，用于补充：

- Task decomposition
- Tool routing
- Context loading
- Permission control
- Verification loops
- Failure recovery
- Memory
- Delegation
- Stop conditions

优先级：

真人专家实践 > 多案例验证后的研究方法 > Agent执行机制 > 一次性Prompt技巧。

Agent经验只有在经过人类研究者重新解释和验证后，才能进入Skill Registry。
