# Personal Research OS v2.0

本项目由以下主线组成：

> Human Sovereignty → Expert Practice Distillation → Skill Registry → Gateway → Runtime → Validation → Research Memory

## 快速开始

1. 阅读 `00_MASTER_WORKFLOW.md`
2. 阅读 `01_governance/`
3. 将真人专家材料放入 `02_expert_distillation/00_inbox/`
4. 使用 `02_expert_distillation/01_distillation_prompt.md` 进行第一次蒸馏
5. 按 `09_templates/skill_template.md` 创建Candidate Skill
6. 经人工审核后进入 `03_skill_registry/`
7. 建立Gateway后，再让Hermes/Codex/Python等执行

## 原则

不要从“写一个超级Agent”开始。先把专家能力固化成经过验证的Skill。
